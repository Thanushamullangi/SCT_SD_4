# Web Scraping Project – Task 04

## Project Title
Web Scraping for Extracting Product Information

---

##  Description
This project is developed using Python to extract product details such as
Name, Price, and Rating from an online e-commerce website.
The extracted data is stored in a CSV file for easy access and analysis.

The website used for scraping is:
https://books.toscrape.com/

---

## Technologies Used
- Python 3
- Requests Library
- BeautifulSoup Library
- CSV Module

---

##  Project Files
- scraper.py  → Main Python program
- products.csv → Output file containing scraped data
- README.md → Project documentation
